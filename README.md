# Media Scraper

Автоматический скрапер метаданных для локальной медиатеки.

**Идёт постепенная миграция на TMDB для повышения точности данных**

Получает информацию:
 - о фильмах с **Кинопоиска** через [kinopoiskapiunofficial](https://kinopoiskapiunofficial.tech)
 - о сериалах с **TMDB** через [TMDB API](https://www.themoviedb.org)
и создаёт файлы в формате, совместимом с **Kodi**.

> **Цель — минимальное вмешательство в имена файлов. Если обработка не удалась (например, не найден год или нет совпадений в API), файл пропускается с уведомлением в Telegram.**


## Ожидаемая структура медиатеки
```
MEDIA_ROOT_PATH/  
├── Movies/ - (фильмы)  
|   └──Movie.folder.1/  
|   |   └──.actors  
|   |   |   └──first_name_last_name.jpg  
|   |   |   └──...  
|   |   └── Movie.1.ext  
|   |   ├──Movie.1-banner.jpg  
|   |   └──Movie.1-fanаrt.jpg  
|   └──Movie.folder.2/  
|   |   └──Структура идентична с Movie.1/  
├── Cartoons/ - (мультфильмы)  
|   └──Структура идентична с Movies/  
└── Serials/ - (сериалы)  
    └── Название сериала/
        ├── tvshow.nfo
        ├── poster.jpg
        ├── fanart.jpg
        ├── .actors/
        │   ├── actor1.jpg
        │   └── ...
        ├── Season 01/
        │   ├── S01E01.mkv
        │   ├── S01E01.nfo
        │   └── season01-poster.jpg
        └── Season 02/
            └── (аналогично Season 01)  
```

### Запуск
1. Переименуйте `.env.example` в `.env` и заполните согласно комментариям.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустите:
   (фильмы)
    ```bash
    python src/main.py
    ```
   (сериалы)
   ```bash
    python src/tmdb.py
    ```
#### Особенности
Фильмы: Извлекает название и год из имени файла (разделители _, , ()). При отсутствии года или неоднозначном результате — пропускает файл с уведомлением.
Сериалы: Определяет сезон/эпизод по шаблону S01E01.
Уведомления: Все ошибки и пропущенные файлы отправляются в Telegram для ручной обработки.
